# NexusCode: contexto de la empresa

> **Nota:** la asignatura de IPE II está convalidada. Este documento solo presenta la empresa ficticia lo justo para entender quién desarrolla SABITECH WEB. No se incluye plan de personal, análisis económico ni plan de viabilidad completo.

## 1. Quién es NexusCode

**NexusCode, S.L.** es una empresa ficticia de desarrollo web creada por los tres integrantes del equipo. Su actividad principal es el diseño y desarrollo de aplicaciones web para eventos, asociaciones y pequeñas empresas.

La empresa trabaja con un modelo sencillo: analiza la necesidad del cliente, diseña una solución ajustada al presupuesto, la desarrolla por fases y ofrece soporte posterior. Para este proyecto, NexusCode actúa como proveedor técnico de las jornadas SABITECH.

## 3. Relación con SABITECH

SABITECH necesita gestionar las reservas de sus jornadas de charlas tecnológicas. El proceso actual se apoya en hojas de cálculo y mensajes, lo que provoca duplicados y falta de control del aforo. NexusCode propone una aplicación web con:

- Catálogo de charlas y ponentes.
- Registro e inicio de sesión de asistentes.
- Reserva y cancelación de plazas.
- Control del aforo en tiempo real.
- Base para enviar confirmaciones por correo y validar la entrada con QR.

El primer checkpoint entrega el recorrido de reserva funcionando. El correo y el QR quedan diseñados para la siguiente fase.
